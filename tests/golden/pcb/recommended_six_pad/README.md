# 用户提供的六焊盘推荐安装图

`footprint.png` 是本次 PCB 图片输入需求提供的参考图，尺寸单位为毫米。
它用于检查普通焊盘与特殊一脚的宽度差异、尺寸标注的含义，以及缺失信息。

图中可见 6 个焊盘、0.40 横向中心距、6×0.65 纵向焊盘尺寸、1.55 上下外缘
跨距、一脚 0.50 宽及其余 5×0.25 宽。只有一脚显式标号。
封装名称、本体尺寸、最大高度及其余编号未给出，不构成完整制造规格。

`tests/test_pcb_image.py` 的完整规格通过模拟操作员补充构造；本体尺寸、
高度、封装名称和编号只用于测试生成/校验，不应作为该器件的真实数据。
