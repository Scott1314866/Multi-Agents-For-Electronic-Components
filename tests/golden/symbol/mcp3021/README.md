# MCP3021 图片回归样例

`pin-diagram.png` 是使用者提供的原始引脚图（477×378）。`reading.json` 保存人工可核对的识别答案，用于离线回归；生产代码没有此型号的特例。

图中型号 MCP3021，封装 SOT-23A，左侧从上到下为 1 VDD、2 VSS、3 AIN，右侧从上到下为 5 SCL、4 SDA。1 与 5 同行，3 与 4 同行，主体为竖长矩形。图片没有标注电气类型，采用 PAS。

`tests/test_symbol_image.py` 验证图片校验、识别结果合同、主体比例、共同网格对齐、清晰图片直接生成、低置信度引脚的定向询问，以及缺脚时阻止生成。
